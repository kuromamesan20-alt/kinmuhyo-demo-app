# 勤務表AI自動化アプリ（デモ版）

介護施設の勤務表を、スタッフごとの勤務条件と本人の希望から自動で組み立てるアプリです。
**体験してもらうためのデモ版**で、入っているスタッフ34名はすべて架空の人物です。

このMacの中だけで動きます。インターネットにはつながりません。

---

## 動かし方

### 1. 準備（初回だけ。ここだけネットが必要）

```bash
cd "/Users/kuromamesan/デモ自動勤務表アプリdemo"
/usr/bin/python3 -m venv venv
./venv/bin/python -m pip install -r requirements.txt
```

### 2. 起動

```bash
cd "/Users/kuromamesan/デモ自動勤務表アプリdemo" && SHIFT_APP_PASSWORD=demo2026 ./venv/bin/python -m streamlit run app.py --server.port 8520
```

ブラウザで `http://localhost:8520` を開き、合言葉 **`demo2026`** を入れます。

止めるときはターミナルで `Ctrl + C`。

---

## デモの流れ（5分）

1. **合言葉を入れて開く**
2. **「希望を入力する」タブ** — スタッフ34名 × 日付のマス目。13名分の希望が最初から入っています。
   いくつかセルを「公」（希望休）や「○」（夜勤に入りたい）に変えて **「保存する」**
3. **「勤務表を作る」タブ** — 公休の日数を `9` のまま **「勤務表を作る」**。1〜2分かかります
4. **「Excelをダウンロード」** — いつもの勤務表と同じ体裁のファイルが手元に保存されます

> **デモ前にやっておくこと**: 一度「勤務表を作る」を走らせておくと、本番で待たされません。

---

## 見せどころ

- **希望が反映される** — 「公」を入れた日はちゃんと休みになります
- **同席の制約** — 「この2人は夜勤で一緒にしない」といった条件が7件入っていて、それを守ります
- **人員基準** — 日勤の時間帯ごとの必要人数、夜勤2名・深夜1名を毎日満たします
- **師長が休みの日** — 日勤責任者ができる人を1人立てます（勤務表の「せ」）
- **要確認マーク（★）** — どうしても条件を満たせなかった箇所は隠さずに印を付けます

## 中身の説明

| 場所 | 何が入っているか |
|---|---|
| `app.py` | 画面（Streamlit） |
| `cli.py` | コマンドライン版。9つのサブコマンド |
| `src/shift_scheduler/scheduler.py` | 勤務表を組む本体（OR-Tools CP-SAT） |
| `src/shift_scheduler/condition_parser.py` | 「毎週水曜は休み」などの自由記述を条件に変換 |
| `src/shift_scheduler/excel_export.py` | 勤務表のExcel出力 |
| `data/staff_profiles/case001.yaml` | スタッフ34名の勤務条件（**架空**） |
| `data/staff_profiles/2026-10_希望.yaml` | 2026年10月の希望（**架空**） |
| `config/facility.yaml` | 施設名・病棟名・ユニット名。**ここを書き換えれば別施設向けに見せられます** |
| `docs/アプリの使い方.txt` | エンドユーザー向けの操作マニュアル |

### 施設名を変えて見せたいとき

`config/facility.yaml` を書き換えるだけです。コードは触りません。

```yaml
facility_name: ひまわり苑
ward_label: 第1病棟
units: [ばら, さくら, ゆり, すみれ]
```

書き換えたらアプリを一度止めて（`Ctrl + C`）、起動し直してください。

## 注意

- **Googleスプレッドシート連携は切ってあります。** 希望の保存先は `data/staff_profiles/` のファイルです。
  画面の「保存先」に「この端末のファイル」と出ていれば正しい状態です
- **このデモには実在のスタッフの情報は一切入っていません。** 名前・勤務条件・希望のすべてが架空です
- **インターネットに公開する場合**（Streamlit Cloud）は、サーバーが再起動すると保存した希望が消えます。
  デモとしてはむしろ毎回まっさらになって都合がよいですが、「保存したのに消えた」と言われないよう先に伝えておいてください
